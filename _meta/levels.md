# 掌握度等级映射

> 底层存 0–100 连续分，仅在**展示层**折算为等级。
> 用户对连续分无感，只需知道"掌握到什么程度"。

## 等级定义

| 等级 | 区间 | 含义 | 典型表现 |
|---|---:|---|---|
| `untouched` | raw = 0 | 未触及 | 从未接触过 |
| `aware` | 1–25 | 听说过 | 知道名词，讲不出所以然 |
| `understood` | 26–50 | 理解原理 | 能讲清楚是什么、为什么 |
| `applicable` | 51–75 | 能上手做 | 有实际使用经验 |
| `proficient` | 76–100 | 精通 | 能处理边界情况、能教别人 |
| `rusty` | 特殊 | 生疏了 | `current ≤ peak×0.6 且 peak ≥ 40` |

> `rusty` 与掌握等级**可叠加展示**：如「精通（已生疏）」。

## 展示口径

- **L0 概览**：只给等级 + 学科聚合百分比
- **L1 卡片**：等级 + 上次接触时间 + 证据摘要（不给原始分）
- **L2/L3**：机器推理时才使用连续分与明细

**硬约束**：L0/L1 的数值必须由 L2 聚合计算得出，不得单独维护一份展示数据。

## 学科聚合

学科掌握度 = 该学科下所有知识点 `current_score` 的加权平均，权重为该知识点的重要度（核心 1.0 / 一般 0.6 / 边缘 0.3）。

未触及的知识点计入分母——否则"学得少"会被误显示为"掌握得好"。
