# 区域 → 知识点映射

> 冷启动第三条路径。推断**行业环境与语言环境**，不推断个人特征。

## 推断维度

| 维度 | 例子 | 强度 |
|---|---|---|
| **产业聚集** | 杭州 → 电商与支付；深圳 → 硬件与供应链；北京 → 互联网与内容 | `likely` |
| **语言环境** | 外语环境 → 语言实际应用能力；方言区 → 方言理解 | `strong`（长期居住） |
| **生活常识** | 当地办事流程、交通、气候适应 | `likely` |
| **行业生态** | 区域龙头行业带来的业务认知 | `possible` |

## 中国主要城市/区域

### 北京
- 互联网与内容产业认知 〔likely〕
- 政策与体制相关认知 〔likely〕
- 总部经济与央企生态 〔possible〕

### 上海
- 金融与外贸认知 〔likely〕
- 外企与跨国协作 〔likely〕
- 英语工作环境 〔possible〕

### 深圳 / 东莞
- 硬件与供应链认知 〔likely〕
- 制造业与外贸 〔likely〕
- 创业与快速迭代文化 〔possible〕

### 杭州
- 电商与支付业务认知 〔strong〕
- 平台型产品设计 〔likely〕
- 云计算与数据智能 〔likely〕

### 广州
- 商贸与快消认知 〔likely〕
- 跨境贸易 〔possible〕

### 成都 / 西安 / 武汉
- 区域IT与外包产业 〔possible〕
- 本地生活服务生态 〔likely〕

### 河北 / 秦皇岛
- 港口与物流产业认知 〔likely〕
- 旅游与服务业生态 〔likely〕
- 钢铁冶金与制造业认知 〔possible〕
- 京津冀协同发展背景 〔likely〕

### 其他地区
- 本地产业特色认知 〔possible〕
- 本地生活常识 〔likely〕

## 国际/语言环境

| 环境 | 推断 |
|---|---|
| 英语国家长期居留 | 英语听说读写 〔strong〕、跨文化沟通 〔likely〕 |
| 非英语国家长期居留 | 当地语言基础 〔strong〕、跨文化适应 〔strong〕 |
| 外企工作 | 商务英语 〔strong〕、跨国协作流程 〔likely〕 |
| 方言区成长 | 本地方言理解与表达 〔strong〕〔permanent〕 |

## 使用方式

区域维度**只做加法不做乘法**——它不会提升其他知识点的分数，只追加"环境带来的认知"这一类：

```
用户：计算机本科 + 前端5年 + 杭州
区域推断追加：电商业务流程〔likely〕、支付链路常识〔possible〕
```

## 红线

- ❌ 不得推断收入水平、消费能力
- ❌ 不得推断户籍、家庭背景
- ❌ 不得推断政治立场、宗教信仰
- ❌ 不得用区域做负面推断
- ✅ 只推产业环境、语言环境、生活常识
