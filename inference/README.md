# 背景推断模板

> 冷启动用。按「学历层级 → 工作类型 → 生活区域」三条路径推断用户可能掌握的知识点。

## 核心原则

1. **推断是起点，不是结论**：推断项权重最低（w=5），用户确认后才升到 12
2. **轻量告知，批量确认**：不逐条问，一次性给概览 + 高把握项
3. **可否认**：用户说"这个我没学过" → 标记 `rejected: true`，不参与计算
4. **宁缺毋滥**：只推"几乎必然掌握"的，边缘猜测不推

## 推断强度分级

| 等级 | 含义 | 处理 |
|---|---|---|
| `strong` | 该背景下几乎必然掌握 | 直接铺，raw 初值给 40–60 |
| `likely` | 大概率接触过 | 铺，raw 初值给 25–35 |
| `possible` | 可能接触 | 只在用户确认背景细节后铺，raw 20 |

## 使用流程

```
① 采集：学历（专业+学位）、工作（职业+年限+行业）、区域
② 套模板：三个文件各取交集与并集
③ 合并去重：同一知识点取最高推断强度
④ 生成档案：origin=inferred, raw_score 按强度给初值, confidence 0.4
⑤ 批量告知：
   "根据你【计算机本科 + 前端5年 + 杭州】，我初步标记了约 N 个知识点。
    把握较高的：数据结构、浏览器渲染、React 工程化、电商业务流程。
    有标错的随时告诉我，我会改。"
⑥ 用户确认 → w 升到 12，confidence 升到 0.7
   用户否认 → rejected=true
```

## 文件

| 文件 | 维度 |
|---|---|
| `学历映射.md` | 专业与学位 → 核心课程 → 知识点 |
| `职业映射.md` | 职业与年限 → 技能簇 → 知识点 |
| `区域映射.md` | 地域/语言环境 → 领域知识倾向 |

## 扩展方式

新增一个行业模板 = 在 `职业映射.md` 加一节，无需改任何代码。
模板质量决定冷启动体验，建议按用户所在行业持续增补。

## 红线

- 不得推断**敏感属性**（健康、政治立场、宗教、性取向等）
- 区域推断只推**行业与语言环境**，不推个人特征
- 任何推断必须能追溯依据（"因为你说了 X，所以我推断 Y"）
