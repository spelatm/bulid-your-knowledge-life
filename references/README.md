# references/ · 子文档索引

`SKILL.md` 是主文档，只装**角色、不变量、模式探测、场景路由表**。
每个具体动作的完整规程放在这里，**按当前要做的那件事读一份**，不要全读。

| 文件 | 装什么 | 何时读 |
|---|---|---|
| `onboarding.md` | 状态机 + §0.1–0.6 + §4 | `bootstrap` 返回 `new` / `partial`，或用户刚说背景 |
| `answering.md` | §5 + §5.1 + §7 + §9 | 用户提问、要看知识分布 |
| `recording.md` | §6.1–6.7 | 要往档案写证据、项目、原则、边、技能 |
| `expansion.md` | §0.7 | 背景超出静态模板 / 用户给了网址文献 |
| `manual-mode.md` | §0.8 + §10.4 + 仓库地图 | 没有 `scripts/`，或脚本挂了要降级 |
| `model.md` | §3 + §10.2 + §10.2b + §10.3 | 算分、判状态、改权重、查字段名 |
| `improving.md` | §8 + §10.1 + §10.5 + §10.6 | 用户提系统改进、收尾自查 |

**章节号 §0–§10 跟着内容搬家，不重编号。**
所以 `scripts/` 里指向「§0.7」的提示语仍然有效，只是那句规程现在住在 `expansion.md`。

## 维护规则

- 改某条规则，**只改一处**。发现同一句规矩在两份文档里都有 → 删掉一份，留指针。
- 唯一例外是 `SKILL.md` 的「最小闭环」：它是刻意保留的兜底副本（没有 `references/` 的人也要能跑），
  改动公式或档位时必须**两边同步**，且以 `_meta/*.md` 为最终事实源。
- 新增子文档要同时改 `SKILL.md` 的索引表和这里的表，两处都别漏。
